# uView-Pro Patterns

用于 `uview-pro` 的组件与工具函数问题。

## 适用场景

- 某个组件不会用
- 想要一个最小示例
- 想知道 `$u` 工具函数怎么调

## 推荐做法

```text
先锁定组件名
-> 给最小示例
-> 再补关键参数和事件
```

## 常见错误

```text
❌ 把组件问题当成 uni-app 核心 API 问题
❌ 只贴很长文档，不给最小代码
```

## 正确做法

```text
✅ 先给最小可运行示例
✅ 再补关键 props / 事件
✅ 核心 API 兼容性问题 handoff 到 uni-app-core
```
