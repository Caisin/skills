## 常见错误

```text
❌ 直接把这份参考当成最终回答，忽略用户当前具体问题
❌ 不做取舍，把整份长文照搬给用户
```

## 正确做法

```text
✅ 先提炼与当前问题最相关的片段
✅ 用最小必要内容回答，再按需引导用户查看更完整参考
```
