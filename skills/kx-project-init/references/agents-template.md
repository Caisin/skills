# KX Project Init AGENTS Template

用于 `kx-project-init` 的默认 `AGENTS.md` 初始化模板。

## 推荐模板

```md
# Repository Guidelines

本文件是当前仓库唯一的 AI / Agent 协作说明，后续只维护这一份。

## 沟通与输出规则

- 默认使用中文回答、思考和写注释；只有在用户明确要求英文时再切换。
- 复杂业务逻辑、事务/一致性、迁移/数据结构变更、安全相关以及不直观的框架约定处，需要补充简短中文备注。
- 当仓库内容、目录结构、框架约定或最佳实践发生变化时，需要同步更新 `AGENTS.md` 与仓库内相关 skill。

## 长期记忆文档约定

- 仓库内可提交的长期记忆文档统一放在 `docs/long-term-memory.md`。
- 每次任务结束后，都必须检查该文档是否需要更新。

## 仓库内 skill 维护约定

- repo-local skill 统一放在 `.agents/skills/<name>/`。
- `.agents` 默认来自 git 子模块：`https://github.com/Caisin/skills.git`。
- 新增或调整 skill 时，要同步更新 `SKILL.md / references / evals`。

## 项目专有规范（待补充）

- [ ] 在这里补当前项目的业务边界
- [ ] 在这里补当前项目的目录事实
- [ ] 在这里补当前项目的配置/部署约定
- [ ] 在这里补当前项目的测试/发布约定
```

## 关键点

```text
- 默认模板要带通用规范。
- 但必须明确留下“项目专有规范”空白区。
- 不要把旧项目的私有规则硬复制到新项目。
```

## 常见错误

```text
❌ 只复制通用规则，不给项目专有规范预留空白
❌ 把当前仓库的具体目录事实直接写死进新项目 AGENTS
```

## 正确做法

```text
✅ 初始化通用规范
✅ 预留项目专有规范占位
✅ 后续由新项目按实际情况补齐
```
