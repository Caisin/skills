# Prose Patterns

用于把空泛、含混或历史叙述改成当前可验证事实。

## 替换模式

```text
“提供强大能力” -> 写具体类型、方法和结果
“无缝支持” -> 写默认行为、前置条件和限制
“现在新增” -> 直接描述当前 API
“可能失败” -> 写失败条件与错误类型；未知则标为待核实
```

## 推荐结构

```text
对象与用途 -> 当前行为 -> 边界 -> 示例 -> 验证
```

## 常见错误

```text
❌ 重复标识符名称，没有补充语义
❌ 用绝对路径作为长期说明
❌ 用未来计划描述当前能力
```

## 正确做法

```text
✅ 说明调用边界、状态变化或常见误用
✅ 使用仓库相对路径和稳定名称
✅ 只保留会影响当前使用的历史约束
```
